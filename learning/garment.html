Garment Isolation tryon/garment.py

▶rembg.remove(image)

Not OpenCV — a separate library that runs a pretrained neural network (a background-removal/segmentation model such as U2Net or BiRefNet) to strip the background from a photo, returning an RGBA image where the subject is opaque and everything else is transparent (alpha = 0).

Why it's needed here

The garment photo usually comes with a plain-ish product-shot background (white wall, hanger, mannequin). Before we can warp just the shirt onto a person, we need to know which pixels are shirt vs. background — that's the alpha channel this function produces.

Used in this project
from rembg import remove
rgba = remove(cv2.cvtColor(garment_bgr, cv2.COLOR_BGR2RGBA))
When to reach for it
  • Product photo cleanup, cutting a subject out for compositing, removing backgrounds before feeding an image into another vision pipeline.
It downloads a multi-MB/GB model file the first time it runs, and needs onnxruntime installed. That's why the code wraps it in a try/except and falls back to treating the whole image as opaque if it's unavailable.
▶cv2.cvtColor(..., cv2.COLOR_BGR2RGBA / RGBA2BGRA)

Same function as in pose.py, but here it's also adding/reordering an alpha (transparency) channel, not just swapping red/blue.

Used in this project
rgba = remove(cv2.cvtColor(garment_bgr, cv2.COLOR_BGR2RGBA))   # BGR -> RGBA for rembg
return cv2.cvtColor(rgba, cv2.COLOR_RGBA2BGRA)                  # RGBA -> BGRA for OpenCV
Why both conversions

rembg/PIL-style libraries expect RGBA channel order; OpenCV's convention is BGRA. We convert on the way in and on the way back out so the rest of our OpenCV code (which always assumes BGR(A)) doesn't get color-shifted images.

▶np.where(condition)

Given a boolean array, returns the coordinates (as separate arrays per axis) where the condition is True.

Used in this project
ys, xs = np.where(alpha > 10)   # row/col indices of every "garment" pixel
if len(xs) == 0:
    raise RuntimeError("Garment image appears to be fully transparent/empty.")
When to reach for it
  • Finding the pixels that match a mask/threshold — bounding boxes, centroids, "is there anything here at all" checks.
  • np.where(cond, a, b) (the 3-argument form) is a different, very common use: an elementwise "if/else" that picks from a or b per-pixel — useful for compositing without loops.
Threshold at > 10 rather than > 0 to ignore near-invisible anti-aliased alpha noise around the true edge.
▶mask_slice.max(axis=0) — column-wise reduction

A NumPy array method, not OpenCV: collapses a 2D array down to 1D by taking the max down each column (axis=0 = "collapse rows").

Used in this project
mask_slice = alpha[lo:hi + 1, :]              # a horizontal band near the top/bottom of the garment
cols = np.where(mask_slice.max(axis=0) > 10)[0]  # which columns have ANY opaque pixel in that band
top_left_x, top_right_x = cols.min(), cols.max()
Why

To approximate the garment's shoulder-width (top) and hem-width (bottom) without a full contour/pose model for the clothing itself — cheap and good enough for a roughly front-facing product photo.

When to reach for it
  • Any "does any pixel in this row/column satisfy X" question — collapsing a mask to find extents, projections, or histograms along one axis.
